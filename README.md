# Blanket

轻量级 Windows 桌面留白与小组件工具：自动收起杂乱的桌面图标，把屏幕还给壁纸、时间与音乐。

## 核心功能

- **自动隐藏桌面图标**：鼠标移到屏幕热区自动显示，移开后延时自动隐藏；内置异常退出守护，防止程序意外崩溃导致桌面图标丢失。
- **游戏 / 窗口防误触保护**：默认开启，在玩半屏/全屏游戏或操作前台软件时，自动禁止屏幕边缘误弹快捷栏与主题按钮，并将露在桌面上的时钟、音乐胶囊、歌词与固定监控切换为**鼠标点击穿透**，彻底杜绝游戏甩鼠标或右键走位误弹主窗口与设置界面；回到桌面瞬间恢复全部交互。
- **极简桌面时钟与天气**：**在桌面图标隐藏后自动浮现**（图标显示时自动避让），支持自定义字体、颜色、农历/节气/星座彩蛋，并可根据壁纸明暗自动切换深浅配色。
- **三态桌面音乐胶囊与同步歌词**：基于 Windows 原生 SMTC，**同样在桌面图标隐藏且有媒体播放时显示**（无播放时自动隐身，播放中收起为专辑封面，悬停或双击锁定后展开控制条与进度条，可选桌面同步歌词）。
- **轻量化系统监控**：在屏幕边缘显示 CPU、内存、显卡温度（NVML）、实时网速与网络延迟（Ping），采用逐像素真透明抗锯齿渲染（白底/暗底均无毛边），支持在右侧快捷开关或托盘菜单一键置顶，固定显示在游戏上时自动鼠标穿透不抢点击。
- **日夜主题一键切换**：支持托盘菜单、快捷键与桌面悬浮按钮切换 Windows 浅色 / 深色模式。
- **右侧贴边快捷中枢**：鼠标移至屏幕右边缘呼出（自适应滚动防遮挡），集成 **☕ 屏幕常亮防休眠 / 🌙 一键息屏 / 🧰 联动打开 DeskKit 本地工具箱**、**🍅 独立可自由拖动的桌面番茄钟**、**⚡ 自动列出「下载 / 桌面」最新 5 个文件（左键点「复制」支持直接 `Ctrl+V` 粘贴文件到微信/QQ、浏览器网页端及桌面 AI 软件，右键点「复制」取完整路径）**、**📝 随手待办便签** 与可折叠自定义分组。

## 下载与安装

### 方式一：直接下载使用（推荐，无需安装 Python）

前往右侧 **Releases** 页面，按习惯二选一即可：

- **标准安装版 `Blanket-Setup.exe`**（推荐）：双击按向导安装，自动创建开始菜单与可选桌面图标；不需要时可直接在 Windows「设置 → 应用 → 已安装的应用」或控制面板里**一键标准卸载**（自动清理自启项）。
- **绿色免安装版 `Blanket.exe`**：单个文件放任意文件夹双击即用（配置保存在同目录 `config.json`）；卸载只需关闭开机自启、退出托盘程序后直接删除文件即可。

### 方式二：从源码运行

- **系统**：Windows 10 / Windows 11
- **Python**：Python 3.10 及以上（需包含 Tkinter，Windows 官方安装包默认自带）

安装可选增强依赖（用于音乐胶囊、封面抗锯齿与壁纸亮度采样；不装也能基础运行）：

```bash
pip install -r requirements.txt
```

## 启动方式（源码）

- **日常使用**：直接双击 `Blanket.cmd`（或 `Blanket.lnk` 快捷方式），程序会静默启动并驻留在右下角系统托盘。
- **命令行启动**：
  ```bash
  pythonw launch.pyw
  ```

## 常用操作与快捷键

- **托盘左键**：立即切换桌面图标显示 / 隐藏
- **托盘右键**：打开设置面板、一键开关「游戏 / 窗口防误触」与「📌 置顶系统监控」、切换系统深浅色主题、退出程序
- **全局快捷键**：
  - `Ctrl + Alt + H`：切换桌面图标显示 / 隐藏
  - `Ctrl + Alt + T`：切换 Windows 深色 / 浅色模式
- **音乐胶囊手势**：左键拖动位置、双击锁定展开、`Ctrl + 滚轮` 调大小、`Shift + 滚轮` 调透明度、右键打开音乐与歌词设置

## 运行单元测试

```bash
python -m unittest discover -s tests -v
```

## 联网与隐私说明

Blanket 默认无账号、无统计埋点，除以下两项**可随时关闭**的辅助功能外，其余模块（图标隐藏、桌面时钟、系统监控、SMTC 媒体控制、快捷中枢、随手便签）均 **100% 纯本地离线运行**：

- **桌面同步歌词**（可在「音乐胶囊与歌词设置」中关闭）：当检测到系统正在播放曲目时，仅将当前曲目的**歌名、歌手名与时长**发送至网易云音乐公开歌词接口（`music.163.com`）或海外开源歌词库（`lrclib.net`）查询同步 LRC 文本，不上传任何音频流或本机文件。
- **当地天气**（可在「桌面组件设置」中关闭）：每 **15 分钟**向中国天气网请求一次当地实时气温并缓存在本机；非国内网络或国内源不可用时，回退通过系统定位 / `ipwho.is` / `bigdatacloud.net` 与 `Open-Meteo` 获取天气。

## 兼容性与已知限制

- **桌面视图机制**：隐藏与恢复桌面图标依赖 Windows 传统桌面列表视图（`SHELLDLL_DefView` / `SysListView32`）。若安装了接管桌面图层的第三方整理软件（如 Fences），或未来 Windows 11 版本将桌面彻底替换为纯 XAML 视图，图标显隐控制可能受限。
- **显卡温度采集**：系统监控中的显卡温度通过 NVIDIA 驱动自带 `nvml.dll` 零权限读取，AMD 显卡或核显机型该项将显示为 `—`。
