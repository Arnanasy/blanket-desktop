# Blanket

轻量级 Windows 桌面留白与小组件工具：自动收起杂乱的桌面图标，把屏幕还给壁纸、时间与音乐。

## 核心功能

- **自动隐藏桌面图标**：鼠标移到屏幕热区自动显示，移开后延时自动隐藏；内置异常退出守护，防止程序意外崩溃导致桌面图标丢失。
- **极简桌面时钟与天气**：支持自定义字体、颜色、农历/节气/星座彩蛋，并可根据壁纸明暗自动切换深浅配色。
- **三态桌面音乐胶囊与同步歌词**：基于 Windows 原生 SMTC，无播放时自动隐身，播放中收起为专辑封面，悬停或双击锁定后展开控制条与进度条，可选桌面同步歌词。
- **轻量化系统监控**：在屏幕边缘显示 CPU、内存、显卡温度（NVML）、实时网速与网络延迟（Ping）。
- **日夜主题一键切换**：支持托盘菜单、快捷键与桌面悬浮按钮切换 Windows 浅色 / 深色模式。
- **快捷分组栏**：隐藏桌面图标后依然可以快速打开常用工具与文件。

## 下载与安装

### 方式一：免安装直接用（推荐给普通用户）

无需安装 Python，前往右侧 **Releases** 页面下载最新版 `Blanket.exe`，放到任意文件夹后双击运行即可（个人配置会自动保存在 `Blanket.exe` 同目录的 `config.json` 中）。

### 方式二：从源码运行

- **系统**：Windows 10 / Windows 11
- **Python**：Python 3.10 及以上（需包含 Tkinter，Windows 官方安装包默认自带）

安装可选增强依赖（用于音乐胶囊、封面抗锯齿与壁纸亮度采样；不装也能基础运行）：

```bash
pip install -r requirements.txt
```

## 启动方式（源码）

- **日常使用**：直接双击 `Blanket.cmd`（或 `Blanket.lnk` 快捷方式），程序会静默启动并驻留在右下角系统托盘。
- **命令行启动**：
  ```bash
  pythonw launch.pyw
  ```

## 常用操作与快捷键

- **托盘左键**：立即切换桌面图标显示 / 隐藏
- **托盘右键**：打开设置面板、切换系统深浅色主题、退出程序
- **全局快捷键**：
  - `Ctrl + Alt + H`：切换桌面图标显示 / 隐藏
  - `Ctrl + Alt + T`：切换 Windows 深色 / 浅色模式
- **音乐胶囊手势**：左键拖动位置、双击锁定展开、`Ctrl + 滚轮` 调大小、`Shift + 滚轮` 调透明度、右键打开音乐与歌词设置

## 运行单元测试

```bash
python -m unittest discover -s tests -v
```

> 个人配置保存在本目录 `config.json`（已通过 `.gitignore` 排除，不会泄露本机偏好与位置缓存）。
